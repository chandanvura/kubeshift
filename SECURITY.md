# Security Policy

## Supported Versions
We currently support the latest major version for security updates.

| Version | Supported          |
| ------- | ------------------ |
| >= 1.0  | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

We take the security of KubeShift seriously. If you discover a security vulnerability, please report it via the private vulnerability reporting feature on GitHub or email the maintainers directly. 

**Please do not report security vulnerabilities through public GitHub issues.**

When reporting a vulnerability, please include:
* A description of the vulnerability and its impact
* Steps to reproduce the vulnerability
* Any proposed fixes (if available)

We will endeavor to respond to all reports within 48 hours and will keep you informed of our progress towards a fix.
